# Publication sur GitHub Pages

Ce dossier contient le site statique prêt à publier : `index.html` et ses images dans `Assets/`.

1. Créez un dépôt GitHub.
2. Téléversez le contenu de ce dossier à la racine du dépôt.
3. Dans **Settings > Pages**, choisissez **Deploy from a branch**, la branche `main` et le dossier `/(root)`.
4. Enregistrez et attendez la fin du déploiement. L’adresse du site apparaîtra dans cette même page.

Aucune installation ni compilation n’est nécessaire.
